# Security

Please report security problems with FindADoctor.si (the website, `api.findadoctor.si`, the MCP endpoint or the sign-in flow) by email to **contact@findadoctor.si**, with "Security" in the subject. Don't open a public issue for them.

Include what you found, how to reproduce it, and what it could expose. We reply within 3 business days.

The service's own contact file is at https://findadoctor.si/.well-known/security.txt.

Please don't run load tests or automated scans against the service, and don't try to download the database. Testing within the published daily limits is fine.

This repository holds only documentation, examples and an Agent Skill; the server code is not here.
